Этот репозиторий содержит набор данных для задачи оптического распознавания символов (OCR). Изображения были тщательно размечены вручную с использованием [CVAT](https://www.cvat.ai/). Главная цель проекта — дообучение (fine-tuning) и всестороннее сравнение двух OCR-моделей: **DeepSeek-OCR** и **EasyOCR**.

## 📊 Описание датасета

Датасет состоит из фотографий/сканов с текстом и разделен на две равные части по языковому признаку для оценки мультиязычных возможностей моделей.

- **Общее количество изображений:** 200 шт.
- **🇷🇺 Русский язык:** 100 изображений.
- **🇬🇧 Английский язык:** 100 изображений.
- **Инструмент разметки:** CVAT (Computer Vision Annotation Tool).
- **Формат разметки:** *[Укажи свой формат, например: COCO / YOLO / CVAT XML / JSON]*

## 🎯 Цели проекта

1. **Обучение/Дообучение:** Адаптация моделей DeepSeek-OCR и EasyOCR под специфику собранных данных.
2. **Сравнение точности:** Оценка качества распознавания текста (CER — Character Error Rate, WER — Word Error Rate) на русском и английском языках.
3. **Сравнение производительности:** Замер скорости инференса (Inference time) и потребления ресурсов для обеих моделей.

CVAT — для создания качественных bounding-box'ов и текстовых аннотаций.

DeepSeek-OCR — передовая архитектура, которую мы тестируем на способность эффективно извлекать текст.
